# Book Inventory App

A clean, responsive, and structured Book Inventory application built with HTML5 and CSS3. This project features custom table styling, rating indicators, and precise CSS attribute selectors to manage and display book reading statuses.

## Features

* **Structured Table Layout:** Displays books with columns for Title, Author, Category, Status, and Rate.
* **Dynamic Status Indicators:** Visual status badges for *Read*, *To Read*, and *In Progress* utilizing customized CSS borders and gradients.
* **Rating System:** Dynamic rating elements with customized circular badge fills for books.
* **Advanced CSS Selectors:** Implements attribute selectors, pseudo-classes, and structural selectors to handle complex styling rules.

## Tech Stack

* **HTML5:** Semantic markup (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<span>`).
* **CSS3:** Flexbox, custom linear gradients, attribute selectors, and pseudo-classes (`:nth-child`).
